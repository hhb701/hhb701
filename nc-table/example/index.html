操作方法速查

鼠标

单击单元格设为活动单元格；checkbox 列直接切换
拖拽 / Shift+单击区域选择（上限 100 行）
双击 / Enter / F2进入编辑（select 弹出下拉）
右下角紫点下拖填充手柄：重复选区值模式
表头列边界 8px 热区拖拽调整列宽（最小 50px）
拖拽列头（非冻结列）移动超 5px 进入换位拖拽，紫线指示落点，松手交换列位置；未移动松开=点击排序
单击表头排序：升 → 降 → 取消
表头右侧 ∨ 按钮列设置菜单：筛选/重命名/排序/冻结/隐藏/删除/前后插入字段
数据筛选Excel 式勾选列值过滤（可搜索、多列组合），筛选列显示漏斗标记
右键列头同样打开列设置菜单
单击末尾 + 列添加新字段
滚轮 / Shift+滚轮滚动；Shift+滚轮横向滚动
右侧/底部滚动条拖拽 thumb、点击轨道翻页；垂直条上下：横杠+▲首页 ▲上一页 ▼下一页 ▼+横杠末页
行号区勾选框勾选行；工具栏“勾选”段可切换 多选（表头全选/清空）/ 单选（勾新消旧）
末行“添加一行”单击追加空白记录
操作列 编辑/删除按钮直接触发行操作（Enter 激活主操作）
开关列自定义 switch 类型：单击 / Enter 切换布尔值
备注列自定义 dlg 类型：单击弹自定义对话框录入，确定写回
登记时间列内置 datetime 类型：双击/F2 弹原生日期时间选择器
导出 Excel工具栏按钮：导出当前视图为 .xlsx（尊重排序/筛选/隐藏列）
