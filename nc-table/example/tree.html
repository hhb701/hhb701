NcTable 树形表格 Demo（组织架构）

不修改控件源码，仅用 NcTable.registerCellType() 自定义单元格 + setData() 实现树形展开/收起、缩进参考线、父子勾选级联、节点增删、检索定位与显示格式设置（日期/时间/金额/数字， 基于 updateColumn(key, { formatter })）；约 1,600 节点虚拟滚动。 基础交互见 主 Demo 与 操作指南.md。

组织架构树（4 级：公司 → 部门 → 小组 → 成员）

节点总数 - · 可见行 - · 已展开 - · 勾选行删除后自动重挂树；单击尖括号展开 / 收起；双击名称列可重命名。

树形操作速查

树特有交互

单击 › / ⌄展开 / 收起该节点子树（保持该行位置）
“全部展开 / 收起”批量切换所有分支，配合虚拟滚动浏览 1,600+ 行
勾选“完成”列自动级联该节点的全部子孙
添加子节点在“活动单元格”所在行下挂新节点并自动展开、定位
删除节点连子树一起删除（二次确认，提示子孙数量）
搜索定位按名称模糊匹配第一个节点，自动展开祖先路径并滚动选中
折叠时徽标收起的分支在名称后显示 “· N 项” 子节点数
末行“添加一行”追加一个根节点（公司）

显示格式设置（工具栏“显示格式”面板）

截止日期YYYY-MM-DD / YYYY/MM/DD / YYYY年MM月DD日 / MM-DD 等 7 种日期样式
打卡时间含秒 / 仅时间 HH:mm:ss / 中文日期+分钟 等 6 种日期时间样式
预算金额¥ 千分位两位小数 / 整数元 / “元”后缀 / 美元 / 万元 等 6 种金额样式
工时小数位数 / 带单位 h / 占标准周（40h）百分比
生效范围画布渲染、Ctrl+C 复制、筛选面板选项、Excel 导出（.xlsx 数字列保留原值）；编辑器中始终为原值

通用交互（同主 Demo）

双击 / F2 / 直接键入重命名（编辑器左对齐，缩进以渲染为准）
↑↓←→ / Tab / Enter单元格导航（按展开后的平铺行序）
Ctrl+C/V复制 / 粘贴（平铺视图）
表头拖拽边界调列宽；名称/层级列固定不参与排序
数据筛选与展开状态共存：按勾选值过滤平铺行，展开/收起/增删时筛选保持
排序会破坏父子层级：操作后自动重建树视图并提示

实现说明

树 → 平铺深度优先展开可见节点为 rows，setData() 重建视图
tree 单元格自定义类型：按 row.__level 绘制缩进线、尖括号（›/⌄）、图标、折叠徽标
onClick 热区仅尖括号图标 ±1px 内命中折叠，其余区域正常选择/拖选
行对象 = 节点编辑/勾选直接写回树节点，无需同步
显示格式updateColumn(key,{formatter}) 注入，核心渲染/复制/筛选/导出统一调用
