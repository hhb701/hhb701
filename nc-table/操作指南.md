# NcTable 控件操作指南

> 本控件从 [NocoDB](../nocodb-develop) 的 canvas 表格控件
> `packages/nc-gui/components/smartsheet/grid/canvas` 抽离而来，保留其渲染架构与交互模型，
> 用零依赖原生 JS + Canvas 重写。所有交互行为均对标 NocoDB / Airtable 类"多维表格"网格。
>
> 配套示例：打开 `example/index.html`（右侧有同款操作速查面板）。

---

## 1. 控件结构

一个 NcTable 实例由 4 个覆盖层组成（全部挂在一个容器 div 内）：

```
┌──────────────────────────────────────────────┐
│ canvas（唯一绘制面：表头/单元格/选区/滚动条）    │
│  ├─ meta 列（行号 + 勾选框，宽 80px，可关）     │
│  ├─ 冻结列（fixed，滚动时钉在左侧）             │
│  ├─ 滚动列（随 scrollLeft 平移）                │
│  └─ 表头（32px 高，随滚动列平移）               │
├──────────────────────────────────────────────┤
│ editor   —— 单元格编辑器（DOM input 覆盖层）    │
│ popup    —— select 类型下拉选项（DOM ul）       │
│ scroller —— 自绘横/纵滚动条（DOM，12px 轨道）   │
└──────────────────────────────────────────────┘
```

核心概念：

| 概念 | 说明 |
|---|---|
| **活动单元格** | 紫色 2px 描边的格子，键盘操作的"光标" |
| **选区（range）** | 起点到终点的矩形区域，淡紫底 + 1px 描边；单击时选区=活动格本身 |
| **勾选行（checked）** | meta 列勾选框勾中的行，整行淡紫底，用于批量操作 |
| **填充手柄** | 选区右下角的紫色圆点，向下拖拽复制值 |

## 2. 鼠标操作（详解）

### 2.1 选择单元格

| 操作 | 行为 | 细节 |
|---|---|---|
| 单击单元格 | 该格成为活动单元格，选区收敛为单格 | 若该格是 `checkbox` 列：**直接切换勾选值**；若是 `select` 列：**弹出选项下拉** |
| 按住左键拖拽 | 从按下格到当前格形成矩形选区 | 拖到可视区边缘会自动滚动扩选；**上限 100 行**（同 nocodb `MAX_SELECTED_ROWS`） |
| Shift+单击 | 从活动格到点击格扩展选区 | 活动格不变（描边仍在起点） |
| `Ctrl+A` | 全选整表 | 见键盘篇 |
| Esc | 选区收敛回活动单元格 | 编辑中则先取消编辑 |

### 2.2 编辑单元格

| 操作 | 行为 |
|---|---|
| 双击单元格 | 进入编辑：`text`→文本框、`number`→数字框、`date`→日期框、`datetime`→日期时间框、`select`→下拉弹层；`checkbox`→直接切换值 |
| 单击选中后按 `Enter` / `F2` | 同上 |
| 选中后**直接敲字符** | 用该字符作为初始值进入编辑（nocodb 同款"键入即改"） |
| 编辑中 `Enter` | 提交并**下移**一格 |
| 编辑中 `Tab` / `Shift+Tab` | 提交并**右移 / 左移**一格 |
| 编辑中 `Esc` | 放弃修改 |
| 点击别处 / 滚动 | 自动提交当前编辑 |
| select 弹层中单击选项 | 写入选项 `value`（显示 `label`），弹层关闭 |

> select 下拉弹层带淡紫底色（`#f7f5fd`）与白色单元格区分；当单元格位于表格底部、下方空间不足时，弹层自动**向上翻转**，始终保持在可视范围内。

### 2.3 表头操作与列设置菜单

| 操作 | 行为 |
|---|---|
| 单击列头（非按钮区） | 排序三态循环：**升序 → 降序 → 取消**。取消后本地模式恢复原始插入顺序，远程模式重新拉取（`loadData` 不带 sort） |
| 拖拽列头右边界 **8px 热区** | 调整列宽，最小 50px；拖拽时边界显示紫色描边，松手触发 `column-resize-end` |
| 单击 meta 列表头（左上角勾选框） | 全选 / 清空所有行勾选 |
| 单击每个列头右侧的 **∨ 按钮**（14px 热区） | 打开**列设置菜单**；同列再次点击关闭 |
| **右键列头**任意位置 | 同样打开列设置菜单 |
| 单击末尾 `+` 列头 | 触发 `add-column` 事件（demo 中弹窗输入名称并 `insertColumn`） |

**列设置菜单项**（对应 nocodb `SmartsheetHeaderColumnMenu`）：

| 菜单项 | 行为 / 事件 |
|---|---|
| **数据筛选**（第一项） | 打开 Excel 式筛选面板（见 2.4） |
| 清除本列筛选 | 该列有筛选时出现，一键清除 |
| 重命名字段 | 列头内联输入框，Enter 提交 → `updateColumn(key, {title})`，触发 `column-update` |
| 升序排序 / 降序排序 / 取消排序 | 定向排序 `sort(key, 'asc'|'desc'|null)`，当前方向高亮 |
| 冻结到左侧 / 取消冻结 | 切换 `fixed` 并自动重排（冻结列恒在前），触发 `column-update` |
| 隐藏字段 | 移出可见列（数据保留），触发 `column-hide` |
| 显示隐藏字段（n） | 有隐藏列时出现，一键恢复原位置，触发 `column-show` |
| 前插入字段 / 后插入字段 | 触发 `column-insert {index, ref}`，由宿主决定新列定义（demo 用 prompt + `insertColumn`） |
| 删除字段 | 红色危险项，移除列并联动清理该列排序，触发 `column-delete` |

> `readOnly: true` 时菜单只保留排序类视图操作；列定义 `sortable: false` 时禁用排序项。

> 说明：nocodb 原控件中排序**只能**通过此菜单触发；本控件额外保留了"单击列头快速排序"的便捷行为。

### 2.4 数据筛选（Excel 式）

列设置菜单第一项 **数据筛选**，点击后在该列下方弹出筛选面板：

| 面板元素 | 行为 |
|---|---|
| 搜索框 | 实时过滤下方值列表（按显示文本匹配） |
| 全选（n 个值） | 勾选/取消全部；括号内为该列去重值总数 |
| 值复选列表 | 每行一个去重值，空白值显示为 `(空白)` 并排在最后；数值按大小排序，文本按字典序 |
| 确定 | 应用筛选：**未全选**时只保留勾选值；**全选**时等效清除该列筛选；**全不选**则隐藏所有行 |
| 取消 / 点击外部 / 滚动 | 关闭面板，不改变已生效筛选 |

行为细节：

- **多列组合**：每列独立筛选，行间为 AND 语义（与 Excel 一致）；筛选中的列头显示紫色漏斗标记，菜单出现"清除本列筛选"
- **视图语义**：筛选只改变可见行（内部维护 视图索引→源行 映射），行号、勾选、删除、复制、粘贴、填充、区域选择全部按**可见行**操作且正确映射回源数据；`getData()` 仍返回全量数据
- **与排序共存**：先排序后筛选或反之均可，互不干扰
- **远程模式**：面板仅枚举**已加载块**的去重值（服务端全量 distinct 应由后端提供）；点确定后通过 `setFilter` 清空缓存重新拉取，`loadData` 回调收到 `filters: [{key, values}]` 参数，由服务端完成真实过滤
- API：`table.setFilter(colKey, values|null)` / `table.getFilters()` / `table.clearFilters()`，事件 `filter-change`

### 2.5 meta 列（行号区）

| 操作 | 行为 |
|---|---|
| 单击行勾选框（x≤36px） | 勾选/取消该行，触发 `row-check`；配合 `getSelectedRows()` / `deleteSelected()` 做批量操作 |
| 单击行号数字区 | 选中该行第 1 列（活动格移到行首） |

### 2.6 填充手柄

1. 先选中一个或多个单元格（区域）；
2. 选区**右下角**出现紫色圆点，鼠标靠近变为 `crosshair` 十字光标；
3. 按住圆点**向下（或向上）拖拽**：选区的行值模式会重复填充到经过的每一行（多行选区按整块模式循环，单行选区即复制该行）；
4. 拖拽过程中每写入一格实时触发 `cell-change`（可直接同步后端）；
5. **拖回选区内部则自动回滚**为原值；松手提交。

### 2.7 添加 / 删除记录

| 操作 | 行为 |
|---|---|
| 单击末行"在此处添加一行/记录"占位条 | 追加一条空白记录并成为活动格（仅本地模式） |
| 勾选行 → 工具栏"删除勾选项" | `deleteSelected()`，触发 `rows-delete` |

### 2.8 滚动

| 操作 | 行为 |
|---|---|
| 滚轮（纵向） | 垂直滚动；Shift+滚轮 或触控板横向手势 → 水平滚动 |
| 拖拽右侧/底部滚动条 thumb | 快速定位；thumb 大小按可视比例自绘 |
| 单击滚动条轨道 | 向点击方向翻一页 |
| 键盘导航/拖选到可视区边缘 | 自动滚动跟随 |

远程分块模式（`loadData`）下，滚入未加载区域会先显示灰色 loading 占位条，
数据到达后自动替换——与 nocodb 行为一致。

## 3. 键盘操作（详解）

> 表格容器 `tabindex=0`，单击表格或调用 `table.focus()` 即可接收键盘。

### 3.1 导航

| 按键 | 行为 |
|---|---|
| `↑` `↓` `←` `→` | 移动活动单元格（自动滚动跟随；远程模式触发按块加载） |
| `Tab` / `Shift+Tab` | 右移 / 左移（编辑中则先提交） |
| `PageUp` / `PageDown` | 上下翻一屏 |
| `Home` / `End` | 移到本行首列 / 末列 |
| `Ctrl+Home` / `Ctrl+End` | 移到第一行 / 最后一行 |

### 3.2 编辑与选区

| 按键 | 行为 |
|---|---|
| `Enter` | 编辑中：提交并下移；非编辑：进入编辑（checkbox 列则直接切换值） |
| `F2` | 进入编辑 |
| `Esc` | 取消编辑；非编辑时收敛选区 |
| `Shift+方向键` | 扩展选区 |
| `空格` | checkbox 列：切换值；其他列：不拦截（可输入空格） |
| 任意可打印字符 | 选中状态下直接键入 = 用该字符开始编辑 |
| `Delete` / `Backspace` | **清空整个选区**内容（checkbox 列除外），逐格触发 `cell-change` |
| `Ctrl+A` | 全选 |

### 3.3 剪贴板（对标 nocodb useCopyPaste）

| 按键 | 行为 |
|---|---|
| `Ctrl+C` | 复制选区为 **TSV**（制表符分隔、换行分行；值取列 `formatter` 显示文本，checkbox 输出 `true/false`）。可与 Excel / 多维表格直接互贴 |
| `Ctrl+X` | 复制并清空选区 |
| `Ctrl+V` | 从**活动单元格**起粘贴 TSV，**按列类型自动解析**：<br>· `number`：去千分位转数值，非数字保留原文本<br>· `checkbox`：`true/1/yes/x/✓`（不区分大小写）→ true，其余 false<br>· `select`：忽略大小写匹配选项 `value` 或 `label`，匹配不到保留原文本<br>· 空字符串 → `null`；超出数据范围的部分自动忽略 |

每个被写入的格子触发一次 `cell-change`，整批完成后再触发一次 `paste` 事件。

### 3.4 导出 Excel（.xlsx）

| 操作 | 行为 |
|---|---|
| 工具栏「导出 Excel」/ `table.exportExcel(name)` | 纯 JS 生成合法 `.xlsx`（OOXML 打包 ZIP，无第三方依赖）并触发浏览器下载 |

- 导出范围 = **当前视图**：尊重排序 / 列筛选 / 隐藏列（所见即所得）；`opts.rows` / `opts.columns` 可覆盖
- 数值列写为 Excel 数字单元格，其余写显示文本（`formatter`/`defaultFormatter`，date/datetime 已格式化）
- 完成触发 `export` 事件：`{ filename, rows, bytes }`；`table.buildXlsx(opts)` 仅返回 `Uint8Array`（便于自定义上传/预览）

## 4. 单元格类型

内置 6 种，注册表 `NcTable.registerCellType(type, renderer)` 可无限扩展：

| type | 渲染 | 编辑方式 |
|---|---|---|
| `text` | 左对齐单行，超宽 `…` 截断 | 文本框 |
| `number` | 右对齐，千分位 | 数字框 |
| `checkbox` | 居中勾选框 | 单击/空格/Enter 切换 |
| `select` | 圆角标签（tag） | 下拉弹层（支持 `{label, value}` 对象选项） |
| `date` | `YYYY-MM-DD` | 原生日期框 |
| `datetime` | `YYYY-MM-DD HH:mm` | 原生日期时间框（`datetime-local`） |

自定义类型示例（demo 中的进度条，**可编辑**）：

```js
NcTable.registerCellType('progress', {
  editType: 'input-number',   // 'input' | 'input-number' | 'input-date' | 'input-datetime' | 'select' | null（null=只读/自定义交互）
  parse: (raw) => {           // 编辑提交 / 粘贴 / 填充时把文本解析为值
    const s = String(raw ?? '').trim().replace(/%$/, '')
    if (s === '') return null
    const n = Number(s)
    return isNaN(n) ? s : Math.max(0, Math.min(100, n)) // 钳位 0-100
  },
  render(ctx, p) {            // p: { x, y, width, height, column, row, rowIndex, value, text }
    const v = Math.max(0, Math.min(Number(p.value) || 0, 100))
    ctx.fillStyle = '#ececf1'
    ctx.fillRect(p.x + 8, p.y + p.height / 2 - 4, p.width - 16, 8)
    ctx.fillStyle = v > 80 ? '#1fa958' : '#7157d1'
    ctx.fillRect(p.x + 8, p.y + p.height / 2 - 4, (p.width - 16) * v / 100, 8)
  },
})
```

`editType` 决定编辑方式（配 `input-number` 时列定义还可带 `min`/`max` 约束原生数字框）；
`parse` 同时作用于编辑提交、粘贴与填充，保证自定义类型写入的一定是合法值。
`render` 拿到的是原生 2D context（已做 devicePixelRatio 缩放），可自由绘制。

### 4.1 交互式单元格（onClick / onActivate / cursor）

对应 nocodb `CellRenderer.handleCellClick`。渲染器可实现三个钩子：

| 钩子 | 签名 | 说明 |
|---|---|---|
| `onClick(p, mx, my)` | p=单元格参数（含 `table` 实例），mx/my 为**单元格内局部坐标** | 单击时调用；返回 `true` 表示已消费（不再进入选择/编辑流程） |
| `onActivate(p)` | — | `Enter` 键激活（不定义则回退 onClick 且 mx/my=单元格中心） |
| `cursor(p, mx, my)` | 返回 `'pointer'` 等或 null | 悬停光标 |

demo 的"操作"列即用此机制实现 **编辑 / 删除** 两个按钮：

```js
NcTable.registerCellType('buttons', {
  editType: null,
  cursor: (p, mx, my) => hitOpsButton(mx, my, p.height) ? 'pointer' : null,
  onClick(p, mx, my) {
    const b = hitOpsButton(mx, my, p.height)
    if (!b) return false
    if (b === 'edit') {
      const v = prompt('编辑标题：', p.row.title || '')
      if (v !== null) p.table.updateCell(p.rowIndex, 'title', v)   // 走正常 cell-change 事件
    } else {
      if (confirm('删除该行？')) p.table.deleteRows([p.rowIndex])   // 走 rows-delete 事件
    }
    return true
  },
  onActivate: (p) => { /* Enter = 主操作 */ },
  render(ctx, p) { /* 画两个圆角按钮，命中矩形与 onClick 共用同一坐标函数 */ },
})
```

要点：按钮矩形由纯函数（如 `opsRects(rowHeight)`）计算，`render` 与 `onClick/cursor` 共用，
保证"画在哪"与"点哪命中"永远一致；行高切换后按钮自动垂直居中。

### 4.2 demo 自定义类型一览

| 类型 | 编辑方式 | 说明 |
|---|---|---|
| `progress` | `input-number` + `parse` 钳位 0-100 | 进度条，双击/F2/直接键入编辑 |
| `switch` | `onClick`/`onActivate` 切换布尔 | 开关列（胶囊+圆钮），单击或 Enter 取反 |
| `dlg` | `onClick` 弹自定义 modal | 备注列：弹出对话框（textarea + 确定/取消/Esc），`updateCell` 写回 |
| `buttons` | `onClick` 按局部坐标路由 | 操作列：编辑（prompt）/ 删除（confirm） |

> `onClick`/`onActivate` 的参数对象含 `{ x, y, width, height, column, row, rowIndex, table }`，
> 但**不含 `value`**——当前值请用 `p.row[p.column.key]` 读取。

## 5. 数据模式

### 5.1 本地模式

```js
const table = NcTable.mount('#grid', { columns, rows })
```

`rows` 为普通对象数组；编辑结果直接写回对象；排序会重排内部数组但保留原始顺序快照（取消排序即恢复）。

### 5.2 远程分块模式（虚拟滚动）

```js
const table = NcTable.mount('#grid', {
  columns,
  totalRows: 50000,                 // 服务端总行数
  loadData: ({ offset, limit, sort }) =>
    fetch(`/api/rows?offset=${offset}&limit=${limit}`).then(r => r.json()),
})
```

- 行按 **50 行/chunk**（同 nocodb `CHUNK_SIZE`）缓存；滚动进入未加载区域才发请求，已加载块命中缓存不再请求；
- 未加载行渲染 loading 占位条；
- 表头排序变化会清空缓存并带 `sort` 参数重新拉取当前视口；列筛选（`setFilter`）同理，回调附带 `filters: [{key, values}]` 参数由服务端过滤；
- `table.reload()` 强制丢弃全部缓存重拉。

## 6. API 速查

### 构造

```js
NcTable.mount(el, options)  // el: 选择器/DOM 节点；返回实例
```

| option | 默认 | 说明 |
|---|---|---|
| `columns` | `[]` | `{ key, title, type, width, fixed, sortable, options, formatter, placeholder }` |
| `rows` | `[]` | 本地数据 |
| `loadData` / `totalRows` | — | 远程模式二选一开关 |
| `rowHeight` / `headerHeight` | `32` / `32` | 行高/表头高（nocodb 档位：32/60/90/120） |
| `showMetaColumn` | `true` | 行号+勾选列 |
| `readOnly` | `false` | 只读（禁编辑/填充/粘贴/列宽拖拽） |
| `onCellChange` 等 | — | 回调式事件，等价于 `table.on(...)` |

### 方法与事件

```js
// 数据
table.setData(rows) / table.getData()
table.addRow(data) / table.deleteRows([i]) / table.deleteSelected()
table.updateCell(row, key, value) / table.setTotalRows(n) / table.reload()

// 视图
table.setRowHeight(60) / table.scrollToCell(r, c) / table.sort(colKey)
table.focus() / table.destroy()

// 选区与剪贴板
table.getActiveCell() / table.getSelection()      // {startRow,endRow,startCol,endCol}
table.setActiveCell(r, c)
table.copyText()          // 选区 -> TSV 字符串
table.pasteText(tsv)      // 自活动格粘贴，返回写入格数
table.cutSelection()

// 导出 Excel（纯 JS 生成 .xlsx，导出当前视图）
table.exportExcel(name, opts?)   // 生成并触发下载，返回 Uint8Array；opts:{rows,columns,sheetName}
table.buildXlsx(opts?)           // 仅生成字节，不下载

// 列操作（列设置菜单即建立在这些 API 上）
table.updateColumn(key, {title|width|options|fixed|type|sortable|placeholder|formatter})
table.hideColumn(key) / table.showColumn(key) / table.showAllColumns()
table.getHiddenColumns()
table.deleteColumn(key)   // 仅移除列定义，行数据保留
table.insertColumn(colDef, index)

// 数据筛选（Excel 式，多列 AND；远程模式随 loadData 的 filters 参数下发）
table.setFilter(colKey, values|null)   // values 为允许值数组，null=清除；空白用 null 表示
table.getFilters()                      // [{key, values}, ...]
table.clearFilters()

// 事件：on/off，事件名：
// cell-change selection-change row-check row-select row-add rows-delete
// sort scroll copy paste column-resize column-resize-end error export
// column-menu column-update column-hide column-show column-delete
// column-insert column-added add-column filter-change column-filter-open
// 同时以 CustomEvent('nc-table:<event>') 冒泡派发，可在任意祖先监听
```

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| 键盘无反应 | 表格未获得焦点：单击表格或 `table.focus()` |
| 粘贴没进系统剪贴板 | 浏览器安全策略：`Ctrl+C` 走原生 copy 事件正常；工具栏按钮用 `navigator.clipboard.writeText(table.copyText())` 兜底 |
| select 列没有下拉 | 检查列 `options`；也支持 `{label, value}` 对象数组 |
| 远程模式编辑丢失 | 编辑只改缓存行对象，请在 `cell-change` 里回写服务端 |
| 拖选超过 100 行被截断 | nocodb 同款保护（`MAX_SELECTED_ROWS`），批量操作用勾选行 |
| 想禁用编辑 | 列 type 用自定义只读渲染器（`editType: null`），或整表 `readOnly: true` |

## 8. 与原 nocodb 控件的差异

| 原控件 | 本控件 |
|---|---|
| Vue3 + pinia + nocodb-sdk + 后端 API | 零依赖单文件 JS（UMD，可 `<script>`/`import`/`require`） |
| 30+ 种 UITypes 渲染器 | 5 种内置 + `registerCellType` 扩展点 |
| group-by / 聚合行 / 附件预览 / 行颜色 | 未移植（依赖后端语义） |
| 行高 4 档 + 移动端 | `setRowHeight(px)` 任意值（demo 提供 32/60/90 切换） |
| 虚拟滚动 + chunk 预取 | 同款算法（可视区裁剪 + 50 行 chunk + loading 占位） |
